An FHA case number is the file's identity with HUD. You pull it once, before the appraisal is ordered, and it belongs to the borrower rather than to you.

Key concepts
Case numberHUD's identifier for the loan. Pulled once, at the start.never read
OrderCase number first, appraisal second. The appraisal is ordered against the number.never read
TransferThe number follows the borrower to another lender, and the appraisal goes with it.never read
CancellationA number pulled and not used has to be cancelled, or it blocks the borrower's next file.never read
The order it has to happen in4471 Delgado is at step 1
01 · now
Pull the case number
HUD assigns it. Minutes, not days.
02
Order the appraisal
Against the number, never before it.
03
Underwrite
The number is on every document.
04
Close
It stays with the borrower afterwards.
reversedOrder the appraisal first and it is not attached to a case number, so it does not count. You pay for a second one. Two of the last four FHA appraisals on Pacific Ridge were paid for twice, both for this reason.
