How to read this. Three screens matter. The course studio is where Andrew writes and publishes lessons. Then the same reading screen, built two ways. A says people finish training when they are competing, so it plugs into the branch scoreboard. B says people finish training when it is useful today, so a loan officer's own open loans decide what to read next. Same lessons, same app, opposite idea. Picking one is a business call, not a design call. C is version B with the clutter taken out.

Every screen has a switch marked "show the plumbing". Off, it reads in plain English, which is the version for Andrew. On, the same screen shows Jawad where every number would come from and what would have to be built to produce it. One screen, two audiences, and neither has to learn the other's words.

The sidebar and top bar are the real Origna8 ones, rebuilt exactly, so you are judging it as it would actually look inside the product. A bar across the bottom of every screen jumps between all ten. Nothing is connected to a backend and every name and number is invented.
